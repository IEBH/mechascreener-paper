This repository contains the source code, data analysis pipelines, and LaTeX files for the paper *"MechaScreener: Large Language Model-Based Automated Screening for Systematic Reviews and Research"*.

The workflow is reproducible: it automates the process of cleaning raw data, generating figures/tables via Python, and compiling the final PDF.

## 📊 Data Format

The analysis script expects the following JSON structure:

- **Ground Truth (`data/input_libraries/`):** A dictionary where keys are reference IDs and values contain an `include` boolean.

```json
{ "12345": { "title": "...", "include": true } }
```

- **Predictions (`data/output_results/`):** A dictionary where keys are reference IDs and values are either a single score (1–5) or a distribution of scores.

```json
{ "12345": { "1": 0.05, "5": 0.95 } }
```

## 🛠️ Prerequisites

To build this paper, you need the following software installed on your system:

- **Python 3.10+** (the pinned dependencies in `requirements.txt` require at least 3.10)
- **GNU Make**
- **LaTeX Distribution** (TeX Live recommended)
- **latexmk** (for automated LaTeX builds)

### Linux (Debian/Ubuntu/Pop!_OS) Setup

If you are missing any dependencies, you can install them via:

```bash
sudo apt update
sudo apt install python3-venv make texlive-latex-extra texlive-science texlive-bibtex-extra latexmk
```

## 🚀 Installation

1. **Clone the repository:**

    ```bash
    git clone https://github.com/IEBH/mechascreener-paper.git
    cd mechascreener-paper
    ```

2. **Set up the Python environment:**

    ```bash
    # Create a virtual environment
    python3 -m venv .venv

    # Activate it and install libraries
    source .venv/bin/activate
    pip install -r requirements.txt
    ```

### 📥 Handling Large Data Files (Git LFS)

This repository uses **Git LFS** to manage the large JSON datasets in the `data/` directory.

If you have Git LFS installed, files will be downloaded automatically during `git clone`. If you see small placeholder files instead of full JSON data, run:

```bash
git lfs pull
```

## ⚡ Usage

This project uses a `Makefile` to automate the workflow. Ensure your virtual environment is set up (step 2 above), then simply run:

### Build Everything

Generates the figures and compiles the PDF in one go.

```bash
make
```

*Output:* `paper/main.pdf`

### Other Commands

- `make analysis` - Runs only the Python scripts to update figures and tables.
- `make paper` - Runs only the LaTeX compilation (useful for text edits).
- `make clean` - Removes generated PDFs, figures, and temporary build artifacts.

### 🔧 Configuration

The analysis currently uses a **threshold of 2** to determine inclusion. This means any reference receiving an LLM score of 2, 3, 4, or 5 is treated as a predicted "Include." You can modify this threshold in `src/analysis.py` to observe how specificity and recall change.

## 📊 Data Availability

This repository includes 15 screening libraries:

- **Development Set (5 libraries):** Used for prompt engineering and threshold calibration.
- **Evaluation Set (10 libraries):** Used for independent validation (5 RCT-based reviews, 5 non-RCT reviews).

All data is stored in `data/` and managed via Git LFS.
