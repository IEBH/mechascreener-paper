# MechaScreener: Large Language Model-Based Automated Screening for Systematic Reviews and Research

**Authors:** Connor Forbes, Matt Carter, Justin Clark
**Status:** Draft
**Link:** Not submitted

This repository contains the source code, data analysis pipelines, and LaTeX files for the paper *"MechaScreener: Large Language Model-Based Automated Screening for Systematic Reviews and Research"*.

The workflow is reproducible: it automates the process of cleaning raw data, generating figures/tables via Python, and compiling the final PDF.


## 🛠️ Prerequisites

To build this paper, you need the following software installed on your system:

* **Python 3.8+**
* **GNU Make**
* **LaTeX Distribution** (TeX Live recommended)

### Linux (Debian/Ubuntu/Pop!_OS) Setup

If you are missing any dependencies, you can install them via:

```bash
sudo apt update
sudo apt install python3-venv make texlive-latex-extra texlive-science texlive-bibtex-extra
```

## 🚀 Installation

1. **Clone the repository:**

    ```bash
    git clone https://github.com/connorf25/mechascreener-paper.git
    cd mechascreener-paper
    ```

2. **Set up the Python environment:**

    ```bash
    # Create a virtual environment
    python3 -m venv .venv

    # Activate it and install libraries
    source .venv/bin/activate
    pip install -r requirements.txt
    ```

## ⚡ Usage

This project uses a `Makefile` to automate the workflow. Ensure your virtual environment is set up (step 2 above), then simply run:

### Build Everything

Generates the figures and compiles the PDF in one go.

```bash
make
```

*Output:* `paper/main.pdf`

### Other Commands

* `make analysis` - Runs only the Python scripts to update figures and tables.
* `make paper` - Runs only the LaTeX compilation (useful for text edits).
* `make clean` - Removes generated PDFs, figures, and temporary build artifacts.
